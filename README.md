## Project Name: TileVista

## Purpose

TileVista is a simple web application where users can explore different types of tiles. The main goal of this project is to practice building a full-stack application using Next.js, including authentication, dynamic routing, and working with external data. It also focuses on creating a clean and responsive user interface.

## Live URL
https://tile-vista.vercel.app/
## Github Repository URL
https://github.com/masumgaibandha/tile-vista 

## Key Features
- Users can browse all available tiles
- Search and filter tiles by category
- View detailed information about each tile
- User authentication using email and Google
- Protected routes for logged-in users
- Responsive design for mobile and desktop
- Marquee section to highlight tile items
